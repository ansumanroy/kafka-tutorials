## 📊 Serialization Comparison

### String

```java
Properties props = SerializationHelper.getStringProducerConfig();
producer.send(new ProducerRecord<>(topic, "key", "Hello!"));

// Size: ~13 bytes
// Pros: Simple, readable
// Cons: No structure
```

### JSON

```java
Properties props = SerializationHelper.getJsonProducerConfig();
UserEvent user = new UserEvent("123", "john", "john@example.com", ts);
producer.send(new ProducerRecord<>(topic, user.getUserId(), user));

// Size: ~80-100 bytes
// Pros: Flexible, debuggable
// Cons: Verbose, no schema validation
```

### Avro

```java
Properties props = SerializationHelper.getAvroProducerConfig();
UserV1 user = UserV1.newBuilder()
    .setUserId("123")
    .setUsername("john")
    .setEmail("john@example.com")
    .setTimestamp(System.currentTimeMillis())
    .build();
producer.send(new ProducerRecord<>(topic, user.getUserId(), user));

// Size: ~35-40 bytes
// Pros: Compact, validated, evolution
// Cons: Needs Schema Registry
```

## 🔄 Schema Evolution Patterns

### Backward Compatible (Add Optional Field)

```avro
// V1 → V2
{"name": "phoneNumber", "type": ["null", "string"], "default": null}

// Old consumers ignore new field
// ✅ Works: Old consumer + New data
```

### Forward Compatible (Remove/Default Fields)

```avro
// V2 → V3
// Removed: email
// Added: status with default

// New consumers use defaults for missing fields
// ✅ Works: New consumer + Old data
```

### Full Compatible

```avro
// Only add/remove optional fields with defaults
// ✅ Works: Both directions
```

## 🔍 Common Patterns

### Producer Pattern

```java
// 1. Get Avro producer config
Properties props = SerializationHelper.getAvroProducerConfig();

// 2. Create producer with Avro types
KafkaProducer<String, UserV1> producer = new KafkaProducer<>(props);

// 3. Build Avro record
UserV1 user = UserV1.newBuilder()
    .setUserId("123")
    .setUsername("john")
    .setEmail("john@example.com")
    .setTimestamp(System.currentTimeMillis())
    .build();

// 4. Send (serializer handles Schema Registry)
producer.send(new ProducerRecord<>(topic, user.getUserId(), user));
```

### Consumer Pattern

```java
// 1. Get Avro consumer config
Properties props = SerializationHelper.getAvroConsumerConfig();

// 2. Create consumer with Avro types
KafkaConsumer<String, UserV1> consumer = new KafkaConsumer<>(props);

// 3. Subscribe
consumer.subscribe(Collections.singletonList(topic));

// 4. Poll (deserializer handles Schema Registry)
ConsumerRecords<String, UserV1> records = consumer.poll(Duration.ofMillis(100));

// 5. Process strongly-typed records
for (ConsumerRecord<String, UserV1> record : records) {
    UserV1 user = record.value();
    System.out.println("User: " + user.getUsername());
}
```
